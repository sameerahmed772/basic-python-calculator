# Python Calculator

A simple command-line calculator built with Python. This project demonstrates basic Python programming concepts, including user input, conditional statements, and error handling.

## Features
- Addition, subtraction, multiplication, division, modulus, and square root.
- Error handling for invalid inputs (e.g., division by zero, negative square roots).
- User-friendly menu for selecting operations.
