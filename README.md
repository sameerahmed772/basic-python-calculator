# Python Calculator

A lightweight command-line calculator built with Python. This project focuses on core programming fundamentals, input handling, validation, and arithmetic operations.

## Features

- Addition, subtraction, multiplication, and division
- Modulus and square-root operations
- Interactive operation menu
- Input validation and basic error handling
- Division-by-zero protection
- Negative square-root validation

## Requirements

- Python 3.10+

## Run

```bash
git clone https://github.com/sameerahmed772/basic-python-calculator.git
cd basic-python-calculator
python main.py
```

## Learning Goals

This project demonstrates foundational Python concepts including variables, functions, conditionals, user input, type conversion, and exception handling.
